# Enunciado y reto del proyecto

## Situación de partida

Disponéis de un prototipo de pastillero inteligente o de una simulación del mismo. El dispositivo es capaz de enviar eventos a un backend y de consultar la planificación de tomas.

Vuestro trabajo consistirá en desarrollar la parte de servidor de este sistema.

## Tareas principales

- analizar el problema;
- definir actores, eventos y estados;
- modelar la base de datos;
- diseñar e implementar la API;
- gestionar el registro de eventos;
- calcular el estado de las tomas;
- generar alertas;
- preparar la documentación y la defensa del proyecto.
