# Dossier del proyecto

## Presentación

En este proyecto desarrollaréis el backend de un sistema llamado **VigiaSenior**, orientado al seguimiento de la medicación en personas mayores.

La propuesta parte de una situación realista: un dispositivo físico o simulado registra eventos relacionados con la toma de medicación y se comunica con un backend que debéis diseñar e implementar.

## Qué se espera de vosotros

Se espera que seáis capaces de:

- comprender el problema;
- definir las entidades y reglas del sistema;
- diseñar una API REST coherente;
- implementar el backend;
- probar el funcionamiento del sistema;
- documentar el proceso;
- defender oralmente el trabajo realizado.

## Regla principal

Una toma solo se considerará correcta cuando exista:

**apertura + confirmación dentro de una ventana de tiempo configurable**.
