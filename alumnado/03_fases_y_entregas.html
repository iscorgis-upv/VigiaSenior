03 · Fases, entregas y ritmo de trabajo

El proyecto se organiza por fases para avanzar sin dejar todo para el final. Cada tramo prepara el siguiente y deja una entrega o prueba que permite revisar cómo va el trabajo.

← Volver al índice

Cómo se reparte el trabajo

VigiaSenior se desarrolla en 14 sesiones. La ampliación permite separar mejor análisis, diseño, implementación, pruebas, documentación y defensa. El objetivo no es correr más, sino evitar que todo se concentre en las últimas sesiones.

Fases del proyecto

Fase 1 · Comprensión y análisis

Entender el problema, identificar actores, eventos, estados y reglas de negocio.

Fase 2 · Diseño del sistema

Definir el modelo de dominio y el primer diseño de la API REST.

Fase 3 · Backend y persistencia

Preparar la arquitectura, ejecutar el backend y trabajar con Prisma/SQLite.

Fase 4 · Eventos y lógica

Registrar eventos, actualizar estados de toma, generar alertas y consultar el dashboard.

Fase 5 · Pruebas y cierre

Probar el flujo completo, cerrar la documentación y preparar la defensa final.
