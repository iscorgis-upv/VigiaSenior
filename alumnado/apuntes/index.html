VigiaSenior · Apuntes para desarrollar el backend

Este apartado está pensado para que el alumnado no dependa solo de esquemas o de explicaciones orales. Aquí se explica qué es un backend, cómo se organiza una API, cómo se modelan los datos, cómo se implementan rutas y lógica en el proyecto, y cómo se comprueba el resultado con Postman y Jest.

Express + TypeScript Prisma SQLite actual Postman Jest + Supertest Basado en el repo real
01 Fundamentos 02 Stack 03 Datos 04 Arquitectura 05 API 06 Implementación 07 Postman 08 Jest 09 Glosario

Cómo usar estos apuntes

1
Empieza por el contexto.
Lee primero qué problema resuelve VigiaSenior y qué significa desarrollar su backend. Si no entiendes el objetivo, el código se convertirá en una suma de archivos sin sentido.
2
Diseña antes de codificar.
Modelo de datos, endpoints y flujo de eventos antes de abrir el controlador o el servicio.
3
Implementa por capas.
En este proyecto se trabaja con rutas, controladores, servicios, repositorios, validadores y pruebas. Cada capa tiene una responsabilidad distinta.
4
Prueba continuamente.
No esperes al final para probar. Usa Postman para validar endpoints y Jest para asegurar la lógica y la integración.
