# Hardware de VigiaSenior

## Contenido
- sketches Arduino
- esquemas de conexión
- notas de cableado y pruebas

## Mapeo fijo
- D1..D6 -> sensores/pulsadores
- D7..D12 -> LEDs
- A0 -> botón confirmar
- A1 -> buzzer

## Nota
Para una primera prueba se recomienda:
1. cargar el sketch sin backend
2. validar LEDs, pulsadores y buzzer
3. después cargar el sketch con backend
