# Recursos de apoyo del proyecto

Esta carpeta reúne materiales de referencia útiles para el desarrollo, la contextualización y la revisión del proyecto **VigiaSenior**.

## Qué incluye
- referencias bibliográficas y documentales;
- herramientas recomendadas;
- glosario básico del proyecto.

## Finalidad
Su objetivo es servir como apoyo al trabajo del alumnado y del profesorado, así como facilitar la comprensión del contexto técnico y didáctico del proyecto.
