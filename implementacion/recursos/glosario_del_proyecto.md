# Glosario del proyecto

## Backend
Parte del sistema encargada de la lógica de negocio, persistencia de datos y exposición de servicios.

## API REST
Conjunto de endpoints accesibles mediante HTTP para consultar o registrar información.

## DeviceEvent
Evento enviado por el dispositivo al backend, por ejemplo apertura de cajita o confirmación de toma.

## ScheduledDose
Toma programada para una fecha, hora o franja determinada.

## Alert
Aviso generado por el sistema cuando una toma no se confirma, se detecta una incidencia o se requiere seguimiento.

## Simulación
Representación virtual del comportamiento del prototipo físico, útil para explorar y validar el proyecto sin depender siempre del montaje real.

## Transferibilidad
Capacidad del proyecto para ser comprendido, reutilizado y adaptado por otro docente o grupo de alumnado.
