Uso del escenario

Abre el proyecto en Wokwi o en el entorno compatible que se vaya a utilizar. Revisa primero el diagrama para identificar entradas y salidas. Después ejecuta el sketch y comprueba qué ocurre al activar cada entrada.

Qué no demuestra esta simulación

La simulación no garantiza que un montaje físico vaya a funcionar igual, ni que el backend esté correctamente implementado. Solo permite aislar una parte del sistema y comprobar el flujo lógico. Por eso debe acompañarse de pruebas de API y documentación.

Relación con la entrega

Si el equipo usa simulación, debe indicarlo en la memoria técnica y explicar qué parte del sistema se ha validado con ella. No pasa nada por no tener hardware real si el alcance se declara correctamente y las pruebas están bien documentadas.
