Simulación conectada al backend

Sirve para comprobar el flujo de eventos cuando el backend ya está levantado.

Cómo usar estos archivos

  1. Abre Wokwi y crea un proyecto compatible con Arduino.
  2. Copia el contenido de diagram.json en el diagrama del proyecto.
  3. Copia el contenido de sketch.ino en el archivo principal del sketch.
  4. Ejecuta la simulación y revisa la salida por monitor serie.

Antes de ejecutarla, revisa la URL del backend configurada en el sketch y asegúrate de que la API responde correctamente.
