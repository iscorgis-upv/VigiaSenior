# Wokwi · backend ready

## Objetivo
Preparar una simulación conectable al backend.

## Antes de usar
Debes editar:
- `WIFI_SSID`
- `WIFI_PASSWORD`
- `BACKEND_BASE_URL`

## Qué hace
- conecta por WiFi
- envía `device_online`
- envía `heartbeat`
- registra `box_opened`
- registra `dose_confirmed`
