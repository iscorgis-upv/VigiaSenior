Qué representa este escenario

Este recurso permite simular el comportamiento básico del pastillero sin depender de un montaje físico completo. La finalidad no es sustituir el backend ni el análisis del problema, sino facilitar pruebas controladas y explicar de dónde salen los eventos que recibe la API.

Archivos incluidos

  • diagram.json: define los componentes y conexiones del circuito simulado.
  • sketch.ino: contiene el comportamiento programado del dispositivo.
  • README.html: resume el uso del escenario y sus límites.

Qué debería observar el alumnado

  • Qué acción del usuario genera cada evento.
  • Qué datos necesita el backend para interpretar esa acción.
  • Qué diferencia hay entre simular una entrada y registrar una toma real.
  • Qué limitaciones tiene la simulación respecto a un dispositivo físico.
