# Wokwi · modo local

## Objetivo
Explorar el flujo básico del pastillero sin depender de WiFi ni backend.

## Qué hace
- activa una toma
- parpadea el LED correspondiente
- permite simular apertura con S1..S6
- exige confirmación para validar la toma
- lanza timeout si no se confirma

## Actividades para alumnado
- identificar la cajita activa
- provocar una apertura correcta e incorrecta
- explicar qué estados aparecen por Serial
- modificar tiempos de alerta y confirmación
