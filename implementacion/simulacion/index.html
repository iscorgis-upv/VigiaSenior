Por qué incluir simulación

La simulación permite trabajar el proyecto cuando no hay hardware suficiente, cuando el grupo aún no tiene el backend preparado o cuando se quiere aislar un problema. Para una propuesta transferible, esto es importante: otro docente puede aplicar VigiaSenior aunque no disponga del mismo material físico.

Se ha preparado la simulación con Wokwi, una plataforma online que permite montar y probar circuitos electrónicos desde el navegador. Con Wokwi se puede simular una placa como el ESP32, añadir componentes como LEDs, pulsadores o sensores, escribir el código del microcontrolador y comprobar su comportamiento sin tener todavía el hardware físico delante. Se adjuntan los ficheros para pruebas en local y para simulación con backend.

Vídeo de apoyo: primeros pasos con Wokwi

Antes de trabajar con la simulación de VigiaSenior, puede ser útil ver un ejemplo básico de uso de Wokwi. La idea no es copiar exactamente el montaje, sino entender cómo se colocan componentes, cómo se conecta una placa ESP32 y cómo se comprueba el comportamiento del circuito desde el navegador.

Uso recomendado

  1. Validar primero el comportamiento local: botones, LEDs, buzzer y estados.
  2. Definir qué evento debe generar cada acción.
  3. Probar esos eventos manualmente contra el backend.
  4. Solo después conectar simulación y API si el tiempo lo permite.

La simulación no debe convertirse en una segunda implementación paralela. Su valor está en hacer visible el flujo dispositivo-backend y facilitar pruebas.
