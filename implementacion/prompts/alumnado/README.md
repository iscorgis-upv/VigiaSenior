# Prompts para alumnado

Estos prompts están pensados para ayudar al alumnado a abordar tareas concretas del proyecto sin sustituir el análisis propio ni el trabajo de implementación.

## Uso recomendado
- leer primero el dossier y el enunciado;
- usar estos prompts para tareas parciales;
- revisar y adaptar siempre las respuestas obtenidas;
- no copiar código sin comprenderlo.

## Orden sugerido
1. análisis del problema
2. modelo de datos
3. diseño de API
4. endpoint plan del día
5. lógica de tomas
