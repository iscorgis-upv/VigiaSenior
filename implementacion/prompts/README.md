# Prompts de apoyo para el desarrollo del proyecto

Esta carpeta reúne prompts de apoyo pensados para orientar el uso de asistentes conversacionales durante el desarrollo del proyecto **VigiaSenior**.

Su finalidad no es sustituir el análisis ni la toma de decisiones del alumnado o del profesorado, sino servir como herramienta de apoyo para:

- estructurar el dominio del problema;
- diseñar la API;
- generar esqueletos de implementación;
- revisar la lógica de negocio;
- preparar documentación y demostraciones.

## Organización

- `profesor/`: prompts más completos, pensados para preparar el proyecto, estructurar el repositorio y guiar la implementación.
- `alumnado/`: prompts más acotados, pensados para tareas concretas dentro del desarrollo del backend.

## Recomendación de uso

Se recomienda utilizar estos prompts de forma progresiva, no todos a la vez. Lo aconsejable es comenzar por el análisis y el diseño, y solo después pasar a la generación de código o a la preparación de documentación.
