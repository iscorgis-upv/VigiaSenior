# Prompts para profesorado

Estos prompts están pensados para ayudar al profesorado a estructurar el proyecto **VigiaSenior** y orientar el uso de asistentes de IA o herramientas de apoyo al desarrollo.

## Orden recomendado
1. contexto global del proyecto
2. modelo de dominio
3. diseño de API
4. esqueleto backend
5. lógica de negocio
6. documentación y demo final

## Sugerencia
Conviene lanzar estos prompts de forma secuencial y revisar cada respuesta antes de pasar a la siguiente fase.
