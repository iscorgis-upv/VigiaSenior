Backend

API REST de VigiaSenior

Backend en Node.js, TypeScript, Express y Prisma. Aquí está el núcleo evaluable del proyecto.

Qué hay que revisar

  • src/routes: entrada de la API.
  • src/controllers: validación básica de petición y respuesta HTTP.
  • src/services: reglas de negocio.
  • src/repositories: acceso a datos con Prisma.
  • tests: pruebas de endpoints y de lógica.

Comandos habituales

cd implementacion/backend
npm install
cp .env.example .env
npx prisma generate
npx prisma migrate dev --name init
npm run prisma:seed
npm test
npm run build

Endpoints principales

MétodoRutaUso
GET/healthComprobar que el servidor responde.
GET/api/devices/:deviceId/schedule/todayConsultar el plan del día del dispositivo.
POST/api/devices/:deviceId/eventsRegistrar eventos del pastillero.
GET/api/patients/:patientId/dashboardConsultar resumen del paciente.
GET/api/patients/:patientId/alertsConsultar alertas.
PATCH/api/alerts/:alertId/resolveResolver una alerta abierta.
Regla clave: una apertura de cajita no confirma la toma. Para marcar una toma como correcta debe haber apertura y confirmación dentro de la ventana definida.
