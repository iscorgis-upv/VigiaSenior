Bloques de unidades de programación y RA

Ubicación de VigiaSenior dentro de la programación del módulo 0613 · Desarrollo web en entorno servidor. La propuesta se trabaja en el segundo trimestre, tomando como eje RA5, RA6, RA7, RA8 y RA9.

Organización del módulo

El módulo se organiza en bloques que agrupan distintas unidades de programación y resultados de aprendizaje. Esta distribución permite situar el proyecto dentro de una progresión lógica: primero se trabajan las bases, después la programación en servidor y, finalmente, los servicios web y la integración.

Bloque Unidad de programación
Bloque 1 · Introducción
  • Selección de arquitecturas y herramientas de programación (RA1)
  • Inserción de código en páginas web (RA2)
  • Programación basada en lenguajes de marcas con código embebido (RA3)
Bloque 2 · Programación en entorno servidor
  • Desarrollo de aplicaciones web utilizando código embebido (RA4)
  • Generación dinámica de páginas web (RA5)
  • Utilización de técnicas de acceso a datos (RA6)
Bloque 3 · Servicios web y aplicaciones web híbridas
  • Desarrollo de servicios web (RA7)
  • Generación dinámica de páginas web interactivas (RA8)
  • Desarrollo de aplicaciones web híbridas (RA9)

Relación con VigiaSenior

El proyecto no aparece como una actividad aislada, sino como una propuesta que aprovecha los aprendizajes previos del módulo y los aplica en un caso completo: backend, base de datos, API REST, eventos de un dispositivo IoT o simulación, pruebas y documentación.

RA5 · Lógica y estructura

Se trabaja la separación entre estructura de la aplicación, lógica de negocio y generación dinámica.

RA6 · Acceso a datos

El proyecto necesita persistencia, consultas, actualización de información y control de consistencia.

RA7 · Servicios web

La API REST permite consultar el plan del día y registrar eventos del dispositivo o simulador.

RA8 · Interacción y visualización

Se utiliza para interpretar información, validar entradas y mostrar datos de seguimiento.

RA9 · Integración

Se incorporan librerías, herramientas y código de apoyo para construir una solución completa.

Producto final

El resultado esperado combina backend funcional, pruebas, documentación y defensa oral.
