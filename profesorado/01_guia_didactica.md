# Guía didáctica del proyecto

## Título
**VigiaSenior: backend para la gestión y vigilancia de la medicación en personas mayores**

## Etapa y módulo
- **Ciclo:** CFGS Desarrollo de Aplicaciones Web (DAW)
- **Módulo eje:** 0613 Desarrollo web en entorno servidor

## Descripción breve
Proyecto de carácter tecnológico y social en el que el alumnado desarrolla el backend de un sistema IoT aplicado al seguimiento de la medicación de personas mayores. El hardware del pastillero y una interfaz de consulta ya están disponibles o simulados. El foco de aprendizaje está en el **backend**.

## Producto final
- API REST funcional
- Modelo de datos y persistencia
- Lógica de negocio sobre tomas y alertas
- Integración con dispositivo Arduino Nano ESP32
- Dashboard y datos para frontend
- Documentación técnica y didáctica en GitHub

## Justificación pedagógica
La propuesta combina:
- aprendizaje basado en proyectos
- orientación a producto real o simulado
- dimensión social y Aprendizaje-Servicio
- integración entre análisis, diseño, implementación, pruebas y documentación
