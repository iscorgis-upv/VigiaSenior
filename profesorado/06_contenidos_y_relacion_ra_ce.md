# 4. CONTENIDOS, RESULTADOS DE APRENDIZAJE Y RELACIÓN CON EL PROYECTO

## 4.1. Contenidos del módulo relacionados con VigiaSenior

La programación general del módulo estructura los contenidos en torno a bloques como arquitecturas cliente/servidor, inserción de código, desarrollo con código embebido, acceso a datos, servicios web, páginas dinámicas y aplicaciones híbridas. También incluye contenidos como la conexión a bases de datos, la recuperación y edición de información, la generación de un servicio web, el consumo de servicios y la prueba y documentación del código.

En el proyecto **VigiaSenior**, estos contenidos se concretan en:

- definición de una arquitectura cliente/servidor con componente IoT;
- implementación de una API REST en el entorno servidor;
- persistencia de entidades como paciente, dispositivo, toma, evento y alerta;
- desarrollo de servicios web para consulta y registro de información;
- documentación de la API y del proceso de desarrollo;
- integración de información para su visualización en un dashboard.

## 4.2. Resultados de aprendizaje prioritarios

Aunque el proyecto puede conectarse con varios RA del módulo, los más directamente vinculados son:

- **RA5**: desarrollo de aplicaciones web separando la lógica de negocio de la presentación.
- **RA6**: desarrollo de aplicaciones web de acceso a almacenes de datos.
- **RA7**: desarrollo de servicios web reutilizables y accesibles.
- **RA8**: generación de páginas web dinámicas con tecnologías del servidor.
- **RA9**: desarrollo de aplicaciones web híbridas mediante tecnologías, frameworks y repositorios heterogéneos.

## 4.3. Criterios de evaluación más relevantes para el proyecto

De entre los criterios del módulo, en esta propuesta se priorizan especialmente los siguientes:

- conexión con bases de datos y recuperación de información;
- publicación de información en aplicaciones web;
- creación de servicios web y verificación de su funcionamiento;
- consumo de servicios web;
- aplicación de mecanismos de separación entre lógica de negocio y presentación;
- prueba y documentación del código;
- reutilización de código e integración de información procedente de repositorios heterogéneos.
