# Instrumentos y evidencias de evaluación

## Instrumentos
- rúbrica del proyecto
- rúbrica de la presentación oral
- lista de control de entregables
- revisión del repositorio
- observación del proceso de trabajo
- valoración de pruebas y demostraciones

- modelo del dominio
- diseño de la API
- código del backend
- documentación técnica
- materiales curriculares
- presentación oral
- repositorio completo y ordenado
