# Rúbrica del proyecto

| Criterio | 1. Inicial | 2. En proceso | 3. Adecuado | 4. Muy adecuado |
|---|---|---|---|---|
| Análisis del problema | Poco claro | Parcial | Claro | Muy bien justificado |
| Diseño del dominio y la API | Incompleto | Mejorable | Coherente | Muy coherente y justificado |
| Implementación del backend | Muy limitada | Funcionalidad parcial | Funcional | Funcional y bien estructurada |
| Integración con simulación / hardware | No demostrada | Parcial | Adecuada | Clara y consistente |
| Documentación técnica | Escasa | Básica | Clara | Completa y transferible |
| Organización del repositorio | Confusa | Aceptable | Clara | Muy clara y reutilizable |
