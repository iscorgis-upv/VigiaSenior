# Metodología y DUA

## Metodología
- aprendizaje basado en proyectos
- resolución de un problema significativo
- trabajo cooperativo en grupos de 2-3
- producto técnico con valor social
- revisión iterativa mediante hitos

## DUA / inclusión
- documentación con estructura clara y visual
- plantillas para análisis, API y pruebas
- ejemplos resueltos y tutoriales paso a paso
- reparto de roles flexible
- ajuste de carga y apoyos guiados si procede
