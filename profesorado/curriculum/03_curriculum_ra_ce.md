# Enfoque curricular · RA / CE / contenidos

## Resultados de aprendizaje prioritarios
- **RA4**: aplicaciones web embebidas, mantenimiento de estado, seguridad básica y pruebas
- **RA5**: separación entre presentación y lógica de negocio
- **RA6**: acceso a almacenes de datos, integridad y seguridad de la información
- **RA7**: desarrollo de servicios web
- **RA8**: generación de páginas dinámicas
- **RA9**: aplicaciones web híbridas, reutilización de código y recursos

## Relación con el proyecto
- El dispositivo consulta planificaciones y envía eventos al backend.
- El backend interpreta eventos, actualiza estados y genera alertas.
- La persistencia permite histórico, dashboard y trazabilidad.
- La API REST alimenta el frontend ya proporcionado.
