# Programación de aula por sesiones

## Propuesta de secuenciación (12 sesiones)

### Bloque 1. Análisis y diseño
1. Presentación del reto, contexto social, producto final y roles.
2. Análisis funcional: actores, casos de uso, eventos y estados.
3. Diseño del modelo de datos y del dominio.
4. Diseño de la API REST y revisión.

### Bloque 2. Backend
5. Estructura del proyecto, Express/TypeScript/Prisma.
6. Implementación del modelo de datos y seed.
7. Endpoints del dispositivo: health, schedule, events.
8. Endpoints de paciente: dashboard y alertas.

### Bloque 3. Lógica, pruebas y documentación
9. Lógica de negocio: apertura + confirmación + timeout.
10. Pruebas del backend e integración con hardware/simulación.
11. Documentación del repositorio y material transferible.
12. Preparación y ensayo de la presentación oral.

## Evidencias por bloque
- bloque 1: diagrama de dominio + propuesta de API
- bloque 2: backend funcional básico
- bloque 3: pruebas, documentación y defensa
