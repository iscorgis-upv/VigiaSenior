# Guion de presentación

## Orden recomendado
1. Contexto y problema
2. Enfoque curricular
3. Situación de aprendizaje
4. Secuencia de sesiones
5. Producto técnico
6. Repositorio
7. Demo backend + hardware/simulación
8. Evaluación
9. Conclusiones y mejoras

## Qué conviene enseñar
- README
- estructura del repo
- documentación de profesorado y alumnado
- backend funcionando
- dashboard o endpoints clave
- conexión con Arduino o simulación
